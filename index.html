请假类型为下拉单选，仅可选择其中一项；时间填写（时 00-24，分/秒 00-59）。如有空缺或时间格式有误，将无法生成脚本。
已生成请假文件，在 ProxyPin「脚本 → 导入」选择该 .json 即可。
使用说明
  1. 下载proxypin软件，在软件设置内按照用户ca证书，然后选择启用Https代理。
  2. 点击“生成并下载脚本”，保存得到按“当天日期+小时+分钟+请假文件”命名的 .json（如 20261014-1530-请假文件.json）
  3. 打开 ProxyPin选择底下第三个图标进入配置页面 → 进入 脚本(Script) → 点“导入”按钮，选择新生成的 .json 文件（如之前有导入过，需要将之前的文件删除再导入新文件）；导入后列表出现“请假信息改写”并处于启用状态。
  4. 回到主页点击右下角的开始代理，系统将自动抓取并修改请假信息，正常打开企业微信请假页面就会显示修改后的信息，如需恢复正常，回到软件点击停止代理即可。
  5. 脚本 URL 匹配整个 lyxgqj.gdppla.edu.cn 域名，命中相应路径的响应时自动改写字段（tryLoginUserInfo、getUserHolidayInfoList、getXsqjsqByPkidNew、getReviewInfo）。
